# Personal Instructions

> Copy to `private/CLAUDE.md`, then create the stub that loads it:
> `echo '@private/CLAUDE.md' > CLAUDE.md`. `/setup` can do both for you.

Loaded every session via the one-line `~/.claude/CLAUDE.md` stub, which imports
this file. It lives in your private repo, so it travels between machines and
nothing here is published.

The shipped conventions — identity handling, approval gates, git, data
verification, LaTeX, tool paths, session logging — live in `~/.claude/rules/`
and load alongside this file. Put anything *personal* here instead: how much to
explain, when to ask before acting, tone, anything you would not want a stranger
cloning the repo to inherit.

Rules about how the work is done — estimators, clustering, seed policy, table
style — belong in `private/domain-profile.md`, where the skills that care about
them will read it.

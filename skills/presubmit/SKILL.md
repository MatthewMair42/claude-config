# /presubmit — Pre-Submission Pipeline

Runs the full pre-submission check sequence in one command. Orchestrates three
existing skills, adds gate logic to catch critical issues early, and produces a
single consolidated GO/NO-GO report. **Never edits source files.**

**Usage:** `/presubmit [--skip-bib] [--skip-proofread] [--skip-compile]`

---

## PHASE 0: Setup

1. **Parse skip flags** from the invocation string:
   - `--skip-bib` → skip Phase 1
   - `--skip-proofread` → skip Phase 2
   - `--skip-compile` → skip Phase 3

2. **Locate main `.tex` file:**
   - Glob for `**/*.tex` (exclude `.claude/`, `output/`, `correspondence/`)
   - If a single main file is clear (`main.tex`, `paper.tex`, or contains `\documentclass`), use it
   - If ambiguous, ask the user before continuing

3. **Git checkpoint offer:**
   > "Create a checkpoint commit before running checks? (yes/no)"
   - If yes: run `git add -A && git commit -m "presubmit checkpoint YYYY-MM-DD"`
   - If no: proceed

4. **Initialize results store** (held in context for Phase 4):
   ```
   bib_critical = 0, bib_minor = 0
   proof_critical = 0, proof_minor = 0
   compile_critical = 0, compile_minor = 0
   bib_findings = []
   proof_findings = []
   compile_findings = []
   unresolved_criticals = false
   ```

---

## PHASE 1: Bibliography Validation

**Skip if** `--skip-bib` was passed. Display: `[1/3] Running bibliography validation...`

1. Dispatch the `validate-bib` skill with `--fast` (skips entry quality checks —
   only missing entries, unused refs, and typos are checked).

2. **Parse results** for CRITICAL issues:
   - Missing bibliography entries (cited but not in .bib)
   - Orphaned `\ref{}` keys with no matching `\label{}`

3. **Gate logic — if CRITICAL issues found:**
   > "Bibliography check found [N] critical issue(s):
   > [list issues]
   > Fix these first and re-run, or proceed anyway? (fix / proceed)"
   - `fix` → stop here, display the issues clearly for the user to resolve
   - `proceed` → set `unresolved_criticals = true`, carry issues into final report

4. **Record counts** in results store.

---

## PHASE 2+3: Proofreading and Compilation (parallel)

Display: `[2/3] Running proofreading and compile checks in parallel...`

If both `--skip-proofread` and `--skip-compile` are passed, skip this phase entirely.

**Dispatch both agents simultaneously** (single message, two Agent tool calls):
- Unless `--skip-proofread`: dispatch the `final-proofread` skill as a background agent
- Unless `--skip-compile`: dispatch the `compiletex` skill on the main `.tex` file
  as a background agent

Wait for both to complete, then:

1. **Record proofreading counts** from final-proofread output into results store
   (if run). Do not save a separate final-proofread report — findings fold into
   Phase 4.

2. **Record compile counts** from compiletex output into results store (if run):
   - Fatal errors and undefined references → CRITICAL
   - Overfull/underfull hboxes, warnings → MINOR
   Do not save a separate compile report — findings fold into Phase 4.

---

## PHASE 4: Consolidated Report

Compile all findings into a single report. Save to:
```
correspondence/presubmit/presubmit-YYYY-MM-DD.md
```
(Create `correspondence/presubmit/` if it doesn't exist.)

### Report format

```markdown
# Presubmit Report — YYYY-MM-DD

**Paper:** [title from \title{}]
**Main file:** [path/to/main.tex]
**Phases run:** [bib / proofread / compile] (note any skipped)

---

## Summary

| Phase | Critical | Minor |
|-------|----------|-------|
| 1. Bibliography | N | N |
| 2. Proofreading | N | N |
| 3. Compile | N | N |
| **Total** | **N** | **N** |

## VERDICT: GO / NO-GO

[GO if zero unresolved CRITICALs across all phases]
[NO-GO if any unresolved CRITICALs — list them here with phase reference]

---

## Phase 1: Bibliography Findings

[Full findings from validate-bib, or "Skipped (--skip-bib)" or "No issues found."]

---

## Phase 2: Proofreading Findings

[Full findings from final-proofread, or "Skipped (--skip-proofread)" or "No issues found."]

---

## Phase 3: Compile Findings

[Full findings from compiletex, or "Skipped (--skip-compile)" or "No issues found."]

---

*Generated by /presubmit. No source files were modified.*
```

### Verdict logic

- **GO** — zero unresolved CRITICAL items across all phases
- **NO-GO** — one or more unresolved CRITICALs (including those the user chose to
  proceed past in Phase 1 gate)

After saving, display the Summary table and verdict in the terminal.

---

## Notes

- **Token efficiency:** validate-bib runs with `--fast` (skips entry quality checks).
  Proofreading and compilation run in parallel after the bib gate.
- **Skip flags** are the primary efficiency lever for iterative submission prep:
  once bib is clean, use `--skip-bib` on subsequent runs.
- **Read-only:** this skill never modifies `.tex`, `.bib`, or any source file.
  The only writes are the checkpoint commit (if requested) and the report file.
- **Sub-skill reports:** `final-proofread` and `compiletex` normally save their own
  reports; when run via `/presubmit`, suppress those individual reports and fold
  findings into the consolidated report instead.

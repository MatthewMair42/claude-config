# /verify-data — Session Data Verification

Verify the integrity and documentation coverage of all datasets in `data/clean/`
and produce a persistent, dated verification report.

---

## PHASE 1: Prerequisites

1. Check that `data/dictionary.md` exists. If not:
   > "No data dictionary found at `data/dictionary.md`. Create it first —
   > run `/verify-data` again once the dictionary exists."
   Stop.

2. Glob `data/clean/` for `*.rds` and `*.csv` files. If none found:
   > "No datasets found in `data/clean/` — nothing to verify."
   Stop.

3. Check for a previous verification state at `data/.verify_state.json`.
   Read it if it exists — it stores the N from the last verification per file,
   used to flag unexpected sample changes.

---

## PHASE 2: Run Verification

Write the R script below to `code/R/.verify_data_temp.R`, then run:

```bash
/c/R/R-4.4.2/bin/Rscript.exe code/R/.verify_data_temp.R
```

### R Script

```r
# Auto-generated by /verify-data — do not edit manually

suppressPackageStartupMessages(
  library(jsonlite, warn.conflicts = FALSE)
)

# ── Parse dictionary ──────────────────────────────────────────────────────────
dict_path <- "data/dictionary.md"
lines     <- readLines(dict_path, warn = FALSE)
data_rows <- lines[grepl("^\\|", lines) &
                   !grepl("^\\|[-|]+\\|", lines) &
                   !grepl("Variable", lines)]

dict <- do.call(rbind, lapply(data_rows, function(row) {
  parts <- trimws(strsplit(row, "\\|")[[1]])
  parts <- parts[nchar(parts) > 0]
  if (length(parts) >= 2)
    data.frame(variable = parts[1], type = tolower(trimws(parts[2])),
               stringsAsFactors = FALSE)
}))

if (is.null(dict) || nrow(dict) == 0) {
  cat("DICT_EMPTY: dictionary exists but contains no variable rows.\n")
  quit(status = 0)
}

# ── Load previous N state ─────────────────────────────────────────────────────
state_path <- "data/.verify_state.json"
prev_state <- if (file.exists(state_path)) fromJSON(state_path) else list()
new_state  <- list()

# ── Process each dataset ──────────────────────────────────────────────────────
clean_files <- list.files("data/clean", pattern = "\\.(rds|csv)$",
                           full.names = TRUE)

for (f in clean_files) {
  fname <- basename(f)
  df    <- tryCatch(
    if (grepl("\\.rds$", f)) readRDS(f) else read.csv(f, stringsAsFactors = FALSE),
    error = function(e) { cat("ERROR reading", fname, ":", conditionMessage(e), "\n"); NULL }
  )
  if (is.null(df)) next

  n_current <- nrow(df)
  n_prev    <- prev_state[[fname]]$n
  new_state[[fname]] <- list(n = n_current)

  cat("\n=== FILE:", fname, "===\n")
  cat("N:", format(n_current, big.mark = ","))
  if (!is.null(n_prev)) {
    delta <- n_current - n_prev
    if (delta == 0) cat("  (unchanged since last verification)\n")
    else            cat(sprintf("  (%+d from last verification — CHECK THIS)\n", delta))
  } else {
    cat("  (first verification)\n")
  }

  actual_cols <- names(df)
  dict_cols   <- dict$variable

  # Dictionary coverage
  undocumented <- setdiff(actual_cols, dict_cols)
  unused       <- setdiff(dict_cols, actual_cols)
  cat("\nDICTIONARY COVERAGE\n")
  if (length(undocumented) == 0) cat("  All columns documented\n")
  else cat("  UNDOCUMENTED:", paste(undocumented, collapse = ", "), "\n")
  if (length(unused) > 0)
    cat("  In dictionary but not this dataset:", paste(unused, collapse = ", "), "\n")

  # Missing values (report non-zero only)
  cat("\nMISSING VALUES\n")
  miss <- sort(sapply(df, function(x) sum(is.na(x))), decreasing = TRUE)
  miss <- miss[miss > 0]
  if (length(miss) == 0) cat("  None\n")
  else for (v in names(miss))
    cat(sprintf("  %-30s %s missing (%.1f%%)\n",
                paste0(v, ":"),
                format(miss[v], big.mark = ","),
                100 * miss[v] / n_current))

  # Type-based checks
  id_vars   <- intersect(dict$variable[dict$type == "id"],           actual_cols)
  cont_vars <- intersect(dict$variable[dict$type %in% c("continuous", "cont")], actual_cols)
  cat_vars  <- intersect(dict$variable[dict$type %in% c("categorical", "cat", "factor")], actual_cols)
  bin_vars  <- intersect(dict$variable[dict$type %in% c("binary", "bin", "dummy")], actual_cols)

  if (length(cont_vars) > 0) {
    cat("\nCONTINUOUS VARIABLES\n")
    for (v in cont_vars) {
      x <- df[[v]]
      cat(sprintf("  %-30s min=%-12.4g max=%-12.4g mean=%-12.4g sd=%.4g\n",
                  paste0(v, ":"),
                  min(x, na.rm=TRUE), max(x, na.rm=TRUE),
                  mean(x, na.rm=TRUE), sd(x, na.rm=TRUE)))
    }
  }

  if (length(cat_vars) > 0) {
    cat("\nCATEGORICAL VARIABLES\n")
    for (v in cat_vars) {
      lvls <- sort(unique(df[[v]]))
      if (length(lvls) <= 8) cat(sprintf("  %-30s %d levels: %s\n",
        paste0(v, ":"), length(lvls), paste(lvls, collapse = ", ")))
      else cat(sprintf("  %-30s %d levels\n", paste0(v, ":"), length(lvls)))
    }
  }

  if (length(bin_vars) > 0) {
    cat("\nBINARY VARIABLES\n")
    for (v in bin_vars) {
      pct <- 100 * mean(df[[v]] == 1, na.rm = TRUE)
      cat(sprintf("  %-30s %.1f%% = 1\n", paste0(v, ":"), pct))
    }
  }

  # ID uniqueness
  if (length(id_vars) > 0) {
    cat("\nID UNIQUENESS\n")
    n_unique <- nrow(unique(df[, id_vars, drop = FALSE]))
    label    <- paste(id_vars, collapse = " + ")
    if (n_unique == n_current)
      cat(sprintf("  %s: PASS (%s unique combinations, no duplicates)\n",
                  label, format(n_unique, big.mark = ",")))
    else
      cat(sprintf("  %s: FAIL — %s duplicate rows detected\n",
                  label, format(n_current - n_unique, big.mark = ",")))
  }
}

# ── Persist state ─────────────────────────────────────────────────────────────
write(toJSON(new_state, pretty = TRUE, auto_unbox = TRUE), state_path)
cat("\n--- STATE UPDATED ---\n")
```

If `jsonlite` is not installed, run first:
```bash
/c/R/R-4.4.2/bin/Rscript.exe -e "install.packages('jsonlite', repos='https://cran.r-project.org')"
```

## PHASE 3: Write Verification Report

Parse the script output and write a dated report to `data/verification_YYYY-MM-DD.md`.
If a report for today already exists, overwrite it.

```markdown
# Data Verification — YYYY-MM-DD

**Datasets checked:** [filenames]
**Overall status:** PASS / ISSUES FOUND

---

## [filename]

**N:** [n] — [change note]

### Dictionary Coverage
[pass or list of undocumented columns]

### Missing Values
[none, or table of variable / count / %]

### Variable Checks
[continuous ranges | categorical levels | binary shares]

### ID Uniqueness
[pass/fail]

---

## Issues Requiring Attention

[List any: undocumented columns, unexpected N changes, duplicate IDs,
implausible ranges. If none: "None — verification passed."]

## Next Steps
[If issues: list what needs fixing before analysis proceeds.
If clean: "Verification passed. Safe to proceed with analysis."]
```

---

## PHASE 4: Report to User

Summarise in the conversation:

- Overall status (PASS / ISSUES FOUND)
- Any undocumented columns — offer to add them to `data/dictionary.md` now
- Any N changes — flag prominently with the delta
- Any duplicate ID rows — flag as critical, do not proceed
- Path to the full report: `data/verification_YYYY-MM-DD.md`

**If issues are found:** do not proceed to analysis code until they are resolved
or the user explicitly instructs you to continue anyway.

**If verification passes:** confirm it is safe to proceed and note the report path.

---

## Notes

- `data/.verify_state.json` persists N across sessions. Commit it to git so
  comparisons work across machines and collaborators.
- The temp script `code/R/.verify_data_temp.R` is regenerated each run —
  safe to delete, but harmless to leave.
- For datasets with >1M rows, skip categorical level enumeration and note
  the omission in the report.
- This skill checks `data/clean/` only. Raw data in `data/raw/` is never
  modified and does not need verification.
